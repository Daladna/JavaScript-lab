ОПИСАНИЕ СТРУКТУРЫ ПРОЕКТА «АФИША МЕРОПРИЯТИЙ»
==============================================

Формат: "название папки/файла" - "что в нем находится".
Отступы показывают вложенность. Пометки в скобках:
  [авто]     - создаётся автоматически при работе приложения
  [создать]  - нужно создать или добавить самостоятельно


afisha/ - корневая папка проекта (она же корень репозитория на GitHub)
|
+-- README.md - отчёт в формате README для репозитория: описание работы, инструкция по запуску, документация, примеры, ответы на контрольные вопросы, источники
+-- EXPLANATION.md - подробное объяснение, что и как сделано в проекте, как выполнены требования, меры безопасности, что сказать на защите
+-- REQUIREMENTS_MAP.md - разбор каждого пункта условия задания: в каких файлах и строках он выполнен
+-- DIRECTORY.txt - этот файл, описание всех папок и файлов проекта
+-- .gitignore [создать] - список файлов, которые не нужно загружать в репозиторий (database/afisha.sqlite, database/mail.log)
|
+-- public/ - единственная папка, открытая для браузера (корень веб-сервера)
|   |
|   +-- index.php - единая точка входа: таблица маршрутов (?page=...), выбор контроллера и вызов его метода, страница 404
|   |
|   +-- css/ - стили
|   |   +-- style.css - оформление сайта: шапка, карточки мероприятий, формы, таблицы, сообщения об ошибках и успехе
|   |
|   +-- js/ - скрипты браузера
|       +-- validate.js - клиентская проверка форм до отправки: обязательность, длина, email, число, совпадение паролей, дата не в прошлом, вывод ошибок под полями
|
+-- app/ - внутренняя логика приложения (из браузера напрямую недоступна)
|   |
|   +-- .htaccess - запрещает прямой доступ к папке через Apache
|   +-- config.php - настройки: путь к базе, путь к логу писем, срок жизни ссылки сброса пароля, демо-режим показа ссылки
|   +-- bootstrap.php - подготовка каждого запроса: часовой пояс, подключение helpers.php, автозагрузка классов, запуск сессии
|   +-- helpers.php - общие функции: экранирование вывода e(), redirect(), flash-сообщения, CSRF-токены, render(), abort(), форматирование даты и цены
|   |
|   +-- core/ - ядро приложения
|   |   +-- Database.php - подключение к SQLite через PDO; при первом запуске создаёт базу из schema.sql и добавляет демо-данные
|   |   +-- Auth.php - аутентификация: текущий пользователь, вход, выход, проверка роли, закрытие страниц для гостей и не-админов
|   |
|   +-- models/ - Model: работа с базой данных (все SQL-запросы здесь)
|   |   +-- User.php - пользователи: поиск, создание с хешированием пароля, удаление, смена пароля, проверка данных регистрации, токены восстановления пароля
|   |   +-- Event.php - мероприятия: список, поиск по критериям, создание, изменение, удаление, ближайшие, подсчёт
|   |   +-- Category.php - категории: список, проверка существования, количество мероприятий в каждой
|   |
|   +-- controllers/ - Controller: логика страниц
|   |   +-- HomeController.php - главная страница: собирает ближайшие мероприятия, категории и статистику
|   |   +-- AuthController.php - регистрация, вход, выход, восстановление пароля (запрос ссылки, новый пароль), запись письма в лог
|   |   +-- EventController.php - поиск, «Мои мероприятия», создание, изменение, удаление мероприятий; серверная проверка формы; проверка прав на чужие записи
|   |   +-- AdminController.php - функции администратора: панель, все мероприятия, список и удаление пользователей, создание новых администраторов
|   |
|   +-- views/ - View: HTML-шаблоны страниц
|       +-- home.php - главная страница: приветствие, ближайшие мероприятия, категории, статистика
|       +-- error.php - страницы ошибок 400, 403, 404
|       |
|       +-- layout/ - общая обёртка страниц
|       |   +-- header.php - шапка и меню (разное для гостя, пользователя и администратора), вывод сообщений
|       |   +-- footer.php - подвал и подключение validate.js
|       |
|       +-- partials/ - повторно используемые фрагменты
|       |   +-- event_card.php - карточка мероприятия (на главной и в поиске)
|       |
|       +-- auth/ - страницы аутентификации
|       |   +-- register.php - форма регистрации
|       |   +-- login.php - форма входа
|       |   +-- forgot.php - форма запроса ссылки для восстановления пароля
|       |   +-- reset.php - форма ввода нового пароля
|       |
|       +-- events/ - страницы мероприятий
|       |   +-- search.php - форма поиска и результаты
|       |   +-- form.php - форма мероприятия из 8 полей (одна на создание и редактирование)
|       |   +-- manage.php - таблица мероприятий с кнопками «Изменить» и «Удалить» (для пользователя и для администратора)
|       |
|       +-- admin/ - страницы администратора
|           +-- index.php - панель администратора со ссылками на функции
|           +-- users.php - таблица пользователей с кнопкой удаления
|           +-- create_admin.php - форма создания учётной записи администратора
|
+-- database/ - база данных
|   |
|   +-- .htaccess - запрещает прямой доступ к папке через Apache
|   +-- schema.sql - структура 4 таблиц: users, categories, events, password_resets
|   +-- afisha.sqlite [авто] - файл базы данных SQLite; создаётся при первом запуске; чтобы сбросить данные, удалите его
|   +-- mail.log [авто] - журнал «отправленных» писем со ссылками восстановления пароля; создаётся при первом восстановлении
|
+-- docs/ [создать] - материалы для отчёта
    |
    +-- screenshots/ [создать] - скриншоты для README.md (home.png, search.png, register-errors.png, event-form.png, event-form-errors.png, my-events.png, password-reset.png, admin.png, db-users.png)

ПОРЯДОК ВЫПОЛНЕНИЯ ЗАПРОСА
--------------------------
